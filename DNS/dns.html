DNS

מערכת שמות מתחם - Domain Name System

הצורך

כדי לשלוח מידע לאתר, נדרשת כתובת ה־IP שלו. קל יותר לזכור שם כמו waytosee.io מאשר כתובת IP.

את הכתובת שמתאימה לשם מקבלים באמצעות DNS.

בקשה ותשובה

בקשה מהמחשב לשרת DNS "מה כתובת ה־IP של waytosee.io?"
תשובה משרת DNS למחשב "185.199.108.153" כתובת לדוגמה בהמחשה

הבקשה נשלחת לשרת ה־DNS בפורט 53, כמו שראינו בעמוד Ports.

כתובת שרת ה־DNS מוגדרת במחשב, בדרך כלל באמצעות DHCP.

לאחר קבלת התשובה, אפשר לשלוח מידע לכתובת שהתקבלה.
