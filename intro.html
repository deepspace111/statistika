כשמבינים גבולות — רואים את המערכת
מבוא לרשתות תקשורת מה זו רשת, למה מחשבים צריכים לדבר, ומה זה אינטרנט Address Resolution Protocol — ARP איך מוצאים כתובת Media Access Control Address לפי כתובת Internet Protocol Address בתוך הרשת המקומית Gateway כשיעד מחוץ לרשת — שולחים לשער Domain Name System — DNS תרגום שם כמו google.com לכתובת Internet Protocol Address Internet Control Message Protocol — ICMP בדיקת תקשורת באמצעות Echo Request ו־Echo Reply Transmission Control Protocol — TCP תקשורת אמינה ומסודרת בין מחשבים User Datagram Protocol — UDP תקשורת מהירה ללא בדיקת הגעה Ports איך המחשב יודע לאיזו תוכנה להעביר את המידע Network Address Translation — NAT איך כמה מכשירים בבית יוצאים לאינטרנט דרך כתובת אחת
