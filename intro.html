מבוא המידע הנע דרך הרשת השכבה הפיזית כבלים, אותות ותשתית תנועת המידע Address Resolution Protocol (ARP) תרגום כתובת IP לכתובת MAC Media Access Control בתוך הרשת המקומית IP Address הכתובת הלוגית של היעד Subnet גבולות הרשת המקומית, חלק הרשת וחלק ה־Host Dynamic Host Configuration Protocol (DHCP) קבלת הגדרות רשת באופן אוטומטי Gateway כשיעד מחוץ לרשת המקומית, שולחים לנתב Domain Name System (DNS) תרגום שם כמו google.com לכתובת Internet Protocol Address Internet Control Message Protocol (ICMP) בדיקת תקשורת באמצעות Echo Request ו־Echo Reply Transmission Control Protocol (TCP) תקשורת אמינה ומסודרת בין מחשבים User Datagram Protocol (UDP) תקשורת מהירה ללא בדיקת הגעה Ports איך המחשב יודע לאיזו תוכנה להעביר את המידע Network Address Translation (NAT) איך כמה מכשירים בבית יוצאים לאינטרנט דרך כתובת אחת
