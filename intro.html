כשמבינים גבולות — רואים את המערכת
השכבה הפיזית כבלים,אותות ותחילת תנועת המידע Address Resolution Protocol — ARP איך מוצאים כתובת Media Access Control Address בתוך הרשת המקומית IP Address הכתובת הלוגית של היעד Gateway כשיעד מחוץ לרשת — שולחים לשער Domain Name System — DNS תרגום שם כמו google.com לכתובת Internet Protocol Address Internet Control Message Protocol — ICMP בדיקת תקשורת באמצעות Echo Request ו־Echo Reply Transmission Control Protocol — TCP תקשורת אמינה ומסודרת בין מחשבים User Datagram Protocol — UDP תקשורת מהירה ללא בדיקת הגעה Ports איך המחשב יודע לאיזו תוכנה להעביר את המידע Network Address Translation — NAT איך כמה מכשירים בבית יוצאים לאינטרנט דרך כתובת אחת
