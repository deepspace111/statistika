NAT — סיכום ברור

איך כתובת פרטית אחת שברשת הבית הופכת, בדרך החוצה, לכתובת ציבורית — ואיך הנתב זוכר להחזיר את התשובה למכשיר הנכון.

NAT הוא תרגום כתובות IP. הנתב מחליף כתובת אחת באחרת כאשר חבילה עוברת בין הרשת הפרטית לאינטרנט.

לדוגמה, המחשב בבית שולח חבילה:

מקור: 192.168.1.8:50000
יעד:   8.8.8.8:53

הכתובת 192.168.1.8 היא פרטית ואינה יכולה לעבור באינטרנט. לכן הנתב מחליף אותה בכתובת הציבורית שלו:

מקור: 84.110.20.5:62001
יעד:   8.8.8.8:53

הנתב שומר בטבלת NAT את הקשר:

192.168.1.8:50000 ↔ 84.110.20.5:62001

כשהתשובה חוזרת אל 84.110.20.5:62001, הנתב בודק את הטבלה, מבין שהתשובה שייכת ל־192.168.1.8:50000, מתרגם בחזרה ומעביר אותה למחשב הנכון.

כתובת פרטית (בתוך הרשת) כתובת ציבורית (אחרי התרגום)

למה צריך גם מספרי פורטים?

בבית יכולים להיות מכשירים רבים, אבל לכולם יש בדרך כלל כתובת ציבורית אחת. הפורטים מאפשרים לנתב להבדיל בין החיבורים:

192.168.1.8:50000  →  84.110.20.5:62001
192.168.1.20:51000 →  84.110.20.5:62002

זה נקרא PAT (Port Address Translation) או NAT Overload — הצורה הנפוצה בבתים.

הסוגים העיקריים

סוגמשמעות
Static NATכתובת פרטית אחת מתורגמת תמיד לכתובת ציבורית קבועה
Dynamic NATכתובת ציבורית נבחרת ממאגר כתובות
PATמכשירים רבים חולקים כתובת ציבורית אחת באמצעות פורטים
הרעיון החשוב: NAT אינו שולח את כל המחשבים כישות אחת. הוא מנהל טבלת התאמות שמאפשרת לו לזכור מאיזה מכשיר ומאיזה חיבור יצאה כל תקשורת.

במשפט אחד: NAT מחליף את זהות המקור הפרטית בזהות ציבורית בדרך החוצה — וזוכר כיצד להחזיר את התשובה למכשיר הנכון.
