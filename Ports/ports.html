Ports

פורט - Port מאפשר להפנות את המידע לשירות המתאים באותו מכשיר

שרת - Server

שרת - Server הוא מחשב או תוכנה המספקים שירות למחשבים או לתוכנות אחרים.

כתובת ופורט

כתובת IP מציינת לאן ברשת נשלח המידע. פורט - Port מאפשר להפנות את המידע לשירות המתאים באותו מכשיר. מספר הפורט נפרד מכתובת ה־IP.

שירות מערכת שמות מתחם - Domain Name System ‎(DNS) מתרגם שם של אתר, כמו waytosee.io, לכתובת IP. הוא יוסבר בהרחבה בהמשך.

פורט יעד - Destination Port

באותו שרת יכולים לפעול אתר אינטרנט מאובטח בפורט 443 ושירות DNS בפורט 53. כתובת ה־IP זהה לשניהם, ומספר פורט היעד - Destination Port מאפשר להבחין בין השירותים.

פורט מקור - Source Port

גם בצד השולח מופיע פורט מקור - Source Port. בפנייה מהדפדפן לאתר, בדרך כלל מוקצה פורט מקור זמני. למשל:

כיווןפורט מקורפורט יעד
מהמחשב לאתר51024443
מהאתר למחשב, בתשובה44351024

בתשובה, המספרים מחליפים תפקידים: פורט המקור של הבקשה הוא פורט היעד של התשובה.

פורט המקור, יחד עם כתובות ה־IP ופורט היעד של הבקשה, מאפשר לשייך את התשובה לחיבור המתאים ולתוכנה שמשתמשת בו, למשל הדפדפן. כך אפשר לקיים כמה חיבורים במקביל באותו מחשב.
