דרך הרשת 🌐

בבית שלך כבר קיימת רשת אמיתית.

הטלפון, המחשב, הטלוויזיה החכמה והראוטר
כבר מחוברים יחד ופועלים כל הזמן.

הרשת בבית שלך
היא רשת מקומית קטנה.

LAN = Local Area Network

כלומר:
רשת שפועלת באזור קטן ומקומי
כמו בית, משרד או בית ספר.

כשמבינים איך זה עובד —
פתאום מתחילים לראות דברים חדשים.

ואחרי שרואים —
אפשר גם לשנות. 🌱

אנחנו משתמשים באינטרנט כל הזמן.
שולחים הודעות, גולשים, צופים, עובדים.

אבל רגע אחד לעצור ולשאול:
מה זה אומר בכלל אינטרנט?

בואו נבין את המילה

המילה אינטרנט מורכבת משני חלקים:

Inter = בין
Net / Network = רשת

אינטרנט = חיבור בין רשתות
כמה רשתות שמחוברות יחד
לרשת אחת גדולה.

ומה לגבי הדרך עצמה?

Route = דרך / נתיב

Router = המכשיר שמכוון את הדרך
של המידע בין רשתות.
