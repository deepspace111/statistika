דרך הרשת 🌐

בבית שלך כבר קיימת רשת אמיתית.

הטלפון, המחשב, הטלוויזיה החכמה והראוטר
כבר מחוברים יחד ופועלים כל הזמן.

הרשת בבית שלך
היא רשת מקומית קטנה.

LAN = Local Area Network

כלומר:
רשת שפועלת באזור קטן ומקומי
כמו בית, משרד או בית ספר.

כשמבינים איך זה עובד —
פתאום מתחילים לראות דברים חדשים.

ואחרי שרואים —
אפשר גם לשנות. 🌱

אנחנו משתמשים באינטרנט כל הזמן.
שולחים הודעות, גולשים, צופים, עובדים.

אבל רגע אחד לעצור ולשאול:
מה זה אומר בכלל אינטרנט?

בואו נבין את המילה

המילה אינטרנט מורכבת משני חלקים:

Inter = בין
Net / Network = רשת

אינטרנט = חיבור בין רשתות
כמה רשתות שמחוברות יחד
לרשת אחת גדולה.

למה בכלל צריך אינטרנט?

פעם, רוב המחשבים עבדו לבד
בלי קשר למחשבים אחרים.

אבל אנשים רצו להעביר מידע,
לשתף ולעבוד יחד.

האתגר היה למצוא דרך
להעביר מידע בצורה נוחה ואמינה.

ובמקרים מסוימים זה היה חשוב במיוחד —
למשל אצל צבאות וארגונים גדולים.

עלה רעיון פשוט —
להעביר מידע ממחשב אחד למחשב אחר.

אבל לפני שמידע זז ברשת,
צריך להבין ממה הוא בנוי.

ממה מידע בנוי?

בעולם הדיגיטלי
מידע מיוצג באמצעות 0 ו־1.

גם 0 הוא מידע.
הוא לא “כלום”.

0 ו־1 הם מצבים שונים
שבעזרתם מחשבים מייצגים מידע.

במחשבים ובמערכות אלקטרוניות
המצבים האלה מיוצגים בדרך כלל באמצעות חשמל:

יש זרם / אין זרם.

כל 0 או 1 כזה
נקרא ביט (Bit).

ביט הוא יחידת המידע הקטנה ביותר בעולם הדיגיטלי.

Bit = Binary Digit
כלומר: ספרה בינארית.

אנחנו רגילים לספירה עשרונית (Decimal)
שמבוססת על עשר ספרות:
0 עד 9.

מחשבים עובדים בצורה אחרת.

הם משתמשים בספירה בינארית (Binary)
שמבוססת על שני מצבים בלבד:
0 ו־1.

8 ביטים מרכיבים בייט אחד.

בייטים הם יחידות המידע
שמחשבים משתמשים בהן כדי לשמור, לשלוח ולקבל מידע.

כל מידע דיגיטלי —
תמונה, סרטון, מוזיקה, טקסט או משחק —

בסופו של דבר
מיוצג באמצעות ביטים
של 0 ו־1.

איך המידע עובר?

אם היו מנסים להעביר
את כל המידע בבת אחת,

כל תקלה קטנה בדרך
הייתה יכולה להרוס את הכל.

בנוסף, רשת האינטרנט עמוסה מאוד
והמון מידע עובר בה כל הזמן.

לכן עלה רעיון חכם יותר:

במקום לשלוח הכל ביחד —
מפרקים את המידע לחלקים קטנים.

החלקים האלה יכולים לעבור
בדרכים שונות בתוך רשת האינטרנט.

לפעמים חלק אחד מגיע קודם,
וחלק אחר מגיע מאוחר יותר.

אבל בסוף —
כל החלקים מתחברים מחדש
והמידע נבנה שוב אצל היעד.

כל זה קורה במהירות עצומה —
קרוב למהירות האור.

אם חלק אחד נאבד —
לא הכל נהרס.

כך אפשר לשלוח מחדש
רק את החלק שחסר.

וגם אם חלק מסוים ברשת נופל
או שדרך מסוימת מפסיקה לעבוד,

עדיין אפשר להעביר מידע
בדרכים אחרות.

זאת אחת הסיבות
שהאינטרנט בנוי כרשת גדולה ומבוזרת —
ללא מרכז אחד שמנהל את הכל.

איך מחשבים מבינים אחד את השני?

ואז עלתה שאלה נוספת:

איך מחשב אחד יבין מחשב אחר?

פרוטוקול = הסכמה איך לדבר

מחשבים צריכים שפה משותפת
וחוקים ברורים לתקשורת.

ומה לגבי הדרך עצמה?

Route = דרך / נתיב

Router = המכשיר שמכוון את הדרך
של המידע בין רשתות.

הנתב מכוון את הדרך.道

הנתב (Router)
מחבר בין הרשת המקומית בבית
לבין רשת האינטרנט הגדולה.

הוא עוזר למידע
לצאת מהרשת המקומית
ולהגיע לרשתות אחרות בעולם.

בנוסף, הנתב גם עוזר
לנהל את הרשת המקומית בבית.

הוא מאפשר למכשירים שונים
לתקשר אחד עם השני
ולהתחבר לאינטרנט.

אפשר לחשוב על הנתב
גם כעל שער יציאה — GateWay.

כאשר מידע צריך לצאת
מהרשת המקומית בבית
אל רשתות אחרות באינטרנט,

הוא עובר דרך הנתב.

אז מה זה אינטרנט?

האינטרנט הוא רשת של רשתות
שמחוברות יחד.

הרשתות האלה מדברות אחת עם השנייה
בעזרת חוקים משותפים.

כשמבינים גבולות — רואים את המערכת 🌱
